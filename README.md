## Featured Project

### AI-Driven Risk Prediction and Mitigation Framework

[![Live Demo](https://img.shields.io/badge/Live-Demo-blue)](https://ai-risk-prediction-framework.streamlit.app/)
[![GitHub Repository](https://img.shields.io/badge/GitHub-Repository-black)](https://github.com/VijayxShinde/ai-risk-prediction-framework)

An end-to-end application for predicting, explaining, and analyzing project risks using Jira-style ticket data.

**Features**

- Low, Medium, and High-risk classification
- XGBoost-based prediction
- SHAP explainability
- Isolation Forest anomaly detection
- Prophet time-series forecasting
- NLP-based ticket analysis
- What-If scenario simulation
- Jira REST API and OAuth integration
- Streamlit dashboard
- SQLite authentication and audit trails
- AI-generated mitigation recommendations

**Technologies**

`Python` `XGBoost` `Scikit-learn` `SHAP` `Prophet` `spaCy` `Pandas` `NumPy` `Streamlit` `SQLite` `Jira REST API`
